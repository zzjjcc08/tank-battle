# 🛡️ 坦克大战 · Tank Battle

一个用纯 HTML + Canvas + JavaScript 实现的经典坦克大战（Battle City 风格）小游戏，**单文件、零依赖**，双击 `index.html` 即可在浏览器中游玩。

## ✨ 功能特性

- 🎮 经典玩法：控制坦克守护基地「鹰旗」，消灭全部敌军
- 🧱 多种地形：砖墙（可摧毁）、钢墙（不可摧毁）、水面（阻挡坦克）、草丛（藏匿坦克）
- 👾 4 种敌人：基础、快速、火力、重装（4 点血量），随关卡增多难度提升
- ⭐ 6 种道具：星星（火力升级）、手雷（全屏消灭）、坦克（+1 命）、铁锹（加固基地）、时钟（冻结敌人）、头盔（短暂无敌）
- 🔫 火力升级：最高 3 级，可发射双发子弹、摧毁钢墙
- 📈 无限关卡、积分与最高分（本地保存）
- 🔊 音效（Web Audio 合成，无需音频文件）
- 📱 触屏虚拟按键支持

## 🚀 运行方式

### 本地运行
直接用浏览器打开 `index.html` 即可，无需安装任何依赖或启动服务器。

### 在线游玩（GitHub Pages）
1. 在 GitHub 仓库页面点击 **Settings → Pages**；
2. 将 **Source** 设为 `main` 分支根目录；
3. 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 在线游玩。
